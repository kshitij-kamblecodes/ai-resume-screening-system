# AI Resume Screening System

## Problem Statement
Manual resume screening is time-consuming and inefficient.
This project automates resume–job matching using NLP.

## Approach
- Text preprocessing
- TF-IDF vectorization
- Cosine similarity
- Resume ranking

## Technologies
- Python
- NLP
- Scikit-learn
- TF-IDF

## Output
- Resume match score
- Top-ranked resumes

## How to Run
```bash
cd src
python main.py
